# 开发路线

本轮交付为独立仓库、统一接口和已有能力迁移。下面各阶段按实际真机结果推进。

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| 0：独立项目 | 独立命名和仓库；统一 CLI / JSON；设备信息；迁入实时活动读取；同名可移植技能 | 不依赖旧工作区、对话服务或特定 AI；迁移后真机查询可用 |
| 1：常用设置 | 亮度、音量、低电量等先行，再逐项加入 Wi-Fi / 蓝牙 / 蜂窝 / 飞行模式 / 方向锁定 / 专注模式 | 每项读取、修改、读回；权限 / 版本缺口明确；需要时具备恢复路径 |
| 2：系统闹钟 | 列表、创建、更新、重复、启停、删除 | 真正写入系统时钟；时区和重复规则准确；专用测试闹钟清理完成 |
| 3：提醒事项 | 清单和事项查询、创建、编辑、完成、删除 | 授权流程、稳定 ID、范围查询与读回；不影响无关事项 |
| 4：网络查询 | 搜索、网页提取、浏览器打开、天气实况和预报 | 真实网络来源、时间、分页 / 截断；明确供应方与未配置状态 |
| 5：持续任务 | Live Activity / 服务变化监听，任务停止与通知 | 断连不误判、退出可控、安静处理无变化状态 |
| 6：入口适配 | 可选 HTTP / MCP / 语音入口 | 复用相同服务契约；入口不改变底层验证状态 |

下一实现块：先探测当前 iOS 16.1.1 常用设置的实际读写接口，选择一个可恢复的设置项完成完整闭环，再扩展。仓库迁移本身不切换设备网络，不设置会响铃的闹钟，不创建用户提醒事项。
